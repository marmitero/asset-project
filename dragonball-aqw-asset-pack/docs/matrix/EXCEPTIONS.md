# EXCEÇÕES À MATRIZ

Toda exceção a um padrão congelado deve ser registrada aqui **antes** de o asset ser aprovado.

## Formato

```md
## EXC-000
- **Asset:** DB_...
- **Item da Matriz:** (esqueleto / pivô / altura / camada / paleta / clipe / schema / naming)
- **Exceção:** o que difere
- **Motivo:** por que é necessária
- **Impacto:** quais assets/engines são afetados
- **Migração:** como voltar ao padrão ou como os consumidores devem tratar
- **ADR:** link
- **Aprovado por:** agente/humano
- **Data:**
```
